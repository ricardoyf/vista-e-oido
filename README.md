# vista-e-oido

Apuntes interactivos para estudiar la vista y el oído en gallego, castellano e inglés.

## Estado

Versión: **main actual** (sin versión semántica publicada).

## Funciones

- Mapa mental para organizar los conceptos.
- Cuatro niveles progresivos de aprendizaje.
- Práctica guiada y modo examen.
- Gallego, castellano e inglés.
- Diseño adaptable a móvil y ordenador.
- Aplicación autónoma contenida en un único HTML.

Web: <https://ricardoyf.github.io/vista-e-oido/>
